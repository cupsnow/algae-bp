
Setup
----

Install zephyr: [Developing with Zephyr Getting Started Guide](https://docs.zephyrproject.org/latest/develop/getting_started/index.html)

Copy example `~/zephyrproject/zephyr/sample/basic/blinky` to `package/cc_blinky`

Prepare the environment in terminal

```sh
source ~/.venv/bin/activate
source ~/zephyrproject/zephyr/zephyr-env.sh

export ZEPHYR_TOOLCHAIN_VARIANT=zephyr
export ZEPHYR_SDK_INSTALL_DIR="$HOME/zephyr-sdk-1.0.1"
```

Build for specified board (once)

`west build -p always -b beagleplay/cc1352p7 -d build/cc_blinky package/cc_blinky`

Subsequence build

`west build -d build/cc_blinky`

Output

`build/cc_blinky/zephyr/zephyr.bin`

> Refine for the sample
>
> To ensure each printf() appears immediately, disable stdout buffering once at the beginning of main()
> 
> ```c
> 	setvbuf(stdout, NULL, _IONBF, 0);
> ```
> 
> On BeaglePlay Linux, read the UART (likely /dev/ttyS1):
> 
> ```sh
> # Prefer the board's UART symlink if available
> readlink -f /dev/play/cc1352/uart
> 
> # Configure and display output
> stty -F /dev/play/cc1352/uart 115200 raw -echo \
>     cs8 -parenb -cstopb -crtscts -ixon -ixoff
> cat /dev/play/cc1352/uart
> ```

Flash in BeaglePlay



> python
> 
> ```sh
> python3 -m pip install cc1352-flasher
> cc1352-flasher --help
> 
> # Run on BeaglePlay as root:
> cc1352-flasher --play /path/to/zephyr.bin
> ```
